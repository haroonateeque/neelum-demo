# Neelum — Live Invitation Demo

A standalone wedding invitation demo with a gold envelope gate, three-circle scratch reveal, celebrations, schedule, attire, RSVP, bilingual copy, text-size control, music toggle, and a desktop iPhone preview shell.

## Run

```bash
python3 -m http.server 8090
```

Open `http://localhost:8090/`.

- `/` — demo shell (desktop iPhone, full-screen card on mobile)
- `/card.html` — the invitation itself

The site uses only relative paths, so it can be hosted from any subdirectory.
